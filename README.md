# Dual N-Back Studio

ワーキングメモリを鍛える Dual N-Back トレーニングの Web アプリ（PWA）です。
iPhone のホーム画面に追加すると、独立したアプリとして全画面・オフラインで動きます。

## ホーム画面への追加（iPhone）

1. Safari でこのアプリの公開 URL（`https://<ユーザー名>.github.io/dual-n-back/`）を開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面の「N-Back」アイコンから起動

## データの保存

- 記録・設定は端末内（アプリ内ストレージ）に保存されます。アプリを更新しても消えません。
- 公開 URL を変えると別アプリ扱いになり、記録が見えなくなります。URL は固定してください。
- 設定 →「iCloud／ファイルにバックアップ」で JSON ファイルを書き出し、「ファイルに保存」→ iCloud Drive を選べば iCloud に保存できます。
- 復元は「バックアップから復元」でそのファイルを選びます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・ロジック・内蔵音声 A〜Z） |
| `manifest.webmanifest` | ホーム画面アイコン・全画面表示の設定 |
| `sw.js` | オフライン動作と更新の管理（Service Worker） |
| `chart.umd.js` | グラフ描画ライブラリ（Chart.js 4.4.1） |
| `icons/` | アプリアイコン |

## 更新のしかた

1. `index.html` などを修正して main ブランチに push する
2. GitHub Pages が 1 分ほどで公開版を更新する
3. スマホでアプリを開き直すと新しい版が読み込まれる（`index.html` はネット優先で取得）

`index.html` 以外（アイコン・Chart.js など）を変えたときは、`sw.js` の `VERSION` も書き換えてください。
